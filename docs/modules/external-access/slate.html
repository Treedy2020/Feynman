Slate：浏览器授权，项目受限使用。

复用 dip-slate 0.3.3 的真实 CLI。Feynman 管理私有会话与项目绑定；Agent 通过 MCP 读取结果，不管理账号密钥。

Native browser + PKCE

Slate 不是 Device Code。

所有者指定 HTTPS hostname，原生 CLI 读取 auth/config，打开 Slate 的 cli/auth 页面。随机 loopback 回调接收绑定 state 的短期授权码；PKCE verifier 保留在 CLI 内，交换得到 Slate session。浏览器 Token 不进入回调。Feynman 使用 CLI 的 InMemoryTokenStore 将 session 经私有管道交给 Broker，在线 me 验证成功后才登记 Connection。未完成则命令失败，不创建公开 Connection。

登录进程由所有者 CLI 保持，最多等待 300 秒；不是后台可恢复的 DWS device attempt。终端中断或机器休眠后重新运行 login-slate。Agent 的 access request 只记录需求并提示所有者操作，不自行打开浏览器或批准。

feynman access connections login-slate --hostname sh.slate.star-x.dev
# 显式复用一个已登录的本机 Keychain profile：
feynman access connections import-slate --hostname sh.slate.star-x.dev --profile prod
# 已签发的 Slate session 也可由可信 stdin 提供：
feynman access connections register-slate --hostname sh.slate.star-x.dev --token-stdin

register-slate 接收 Slate session，不接收 StarX 上游 Token。原生登录的 bootstrap / PKCE 差异由 Slate CLI 处理。

Connection + Binding + Grant

认证后仍要选择项目和能力。

feynman access bind PROJECT_ID --provider slate --connection CONNECTION_ID
feynman external-tools grant PROJECT_ID slate.identity.read
feynman external-tools grant PROJECT_ID slate.tasks.read
feynman external-tools invoke PROJECT_ID slate.tasks.read --arguments '{}'

首批能力：slate.identity.read / slate_identity_read；slate.tasks.read / slate_tasks_read（mine，20 条）；slate.projects.read / slate_projects_read（可见项目列表，输出有界）。工具参数固定为 {}；每次调用先核对身份、Grant、有效绑定，再执行真实 CLI。账号可见范围仍是权限上限；本版不是单 Task / Project ACL。

Operator setup

CLI 包在控制面，密钥不进镜像。

python3.13 scripts/opensandbox/local.py prepare-clis --slate-package /path/to/slate/cli
# Server 空闲时重启加载专用 Python 环境；此步骤不认证。
# 非该脚本部署：设置 FEYNMAN_NATIVE_PYTHON 为装有 dip-slate 的解释器。

Broker 清除继承环境，显式传入 hostname 和凭证；CLI session 只进入 InMemoryTokenStore。Token 保存在 Feynman 0700 私有目录中的 0600 文件，不覆盖个人 Keychain。当前未自动轮换 Slate session；失效后重新登录、绑定新 Connection，并停用旧 Connection。

可信单用户 MVP；私有明文不是 Vault。没有容器内直接 dip-slate login、任意 CLI argv、业务写入或通用前端登录状态机。公共规则见 认证与授权流程。
