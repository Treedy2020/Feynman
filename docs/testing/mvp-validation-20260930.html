每例建立新项目、Workspace 和 Thread，不授权实时 DWS，也不让实时认证测试的记忆进入历史案例。事实包记录原始资源 hash 和脱敏变换；精选消息完整性不等于整个历史的完整性。原始消息、方案和详细模型日志仅保存在私有证据目录，不进入本文。

独立运营者通过 Docker 读取容器，核对前后源码集合 / SHA-256、事实内容、初始化清单、Git HEAD / 状态 / 提交数、remote 缺失、宿主认证缓存缺失。容器仅挂载自身命名卷，非 privileged，capabilities 全部丢弃，no-new-privileges，端口仅 loopback。

root Executor 能改变 chmod 权限。当前只读调查是约定 + 运行后检测，不是硬只读沙盒；Docker 网络也没有强制拒绝全部外连，因此不是强隔离的完整历史盲测或不可信多租户安全认证。正式评估需独立只读挂载 / 非 root、显式出网策略、跨项目和工具权限审计。

  • 工作区持久卷和本地状态分别持久化；临时服务结束不等于备份与灾难恢复已验收。
